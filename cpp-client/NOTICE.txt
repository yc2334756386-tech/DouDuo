抖音极简版 / DouGlass 0.20.15

Native iOS client: C++20 business core and Objective-C++ UIKit/WebKit integration.
The read adapter and overall website-context approach draw on DouDuo:
https://github.com/81199000/DouDuo
Copyright (c) 2026 DouDuo contributors. MIT License.
The complete upstream license is included as DOUDUO-LICENSE.txt.

This application is an independent third-party client and has no affiliation
with Douyin. Content and service marks belong to their respective owners.
Login takes place on the official website. Session data stays in the app's
local WebKit website store. This version has no developer-operated backend or analytics SDK.
Likes, collections, follows and blocks are submitted on explicit user actions.
Manual search-page importing reads real results loaded by the official page;
the user controls pagination and completes any verification themselves.
Comment sorting applies only to the comments already loaded in the client.
Messages use the official
website transport with the same local login session, rendered by native UI.
Comments are read-only. Danmaku in the app is read-only.

High-refresh PiP approach inspired by:
CaiWanFeng/PiP — original project and author CaiWanFeng
https://github.com/CaiWanFeng/PiP
Yoroin/GlobalRefresh-PiP — maintained by Yoroin
https://github.com/Yoroin/GlobalRefresh-PiP
