# 抖音极简版 0.10.0

基于 0.7.0 构建 19 对应源码 `d21b8bd`。iOS 18 起，arm64，iOS 26 起使用系统 Liquid Glass。安装包未签名。

- 评论保留只读浏览、展开已有回复和评论图片，移除发评、回复、点赞和语音权限。作品与评论日期显示到分钟。
- 信息与关注、推荐并列，左上角返回原频道，右上角刷新。列表保留原生会话与互动消息入口。点开主页、搜索等列表的作品时从封面放大，返回收回到封面。
- 播放进度从当前白条按横向位移调整，点按不跳转。通过已缓冲播放器读取拖动预览，远处未缓冲的视频仍可能等待。图文小白点滑动切图加触感。
- 调色提供当前作品封面预览及原图对照，新增质感、锐化、护眼和臻享预设。
- 作品操作和更多设置沿用圆角外形展开和收回。移除全局侧滑退出。默认缓出、动画速率 0.8。
- 后台音频用同一个播放器续播，向 iOS 发布正在播放信息与控制指令，支持的设备由系统决定灵动岛显示。后台停用画面采样、取帧与高刷请求，并清理闲置缓冲与图片缓存。切作品时限制预加载数量，取消自动批量抽取缩略图。
- EQ 使用红色频段曲线和旋钮。低中高频独立调节，并提供声场宽度、环绕空间、干湿混音、通透、清晰度、动态增强、低音增强以及 AirPods 增强强度。音效处理和滤波使用 C++20，界面显示是否收到实际音轨采样。低于 iOS 27 的 HLS 音源可能无法使用 EQ。系统空间音频开启时不叠加本机环绕。AirPods 增强依据系统蓝牙输出名称识别。
- 本机成功发送的弹幕与平台明确标识为本人的弹幕显示「我」及描边，复制仍取正文。

C++20 实现数据模型、媒体处理算法及可移植逻辑。Objective-C++ 接入 iOS 原生 UI、音视频与系统媒体控制。需要在官方网页执行的逻辑保留在 WebKit 脚本中。上游 Swift 工程不参与此 IPA 编译。

按要求不运行自动化或真机测试。安装包检查验证编译、资源与哈希。设备后台终止原因、实际听感、灵动岛显示及网络取帧延迟未做真机验证。
