# 抖音极简版 0.20.3

延续以 0.7.0 构建 19 为底包的分支。支持 iOS 18 及以上的 arm64 设备。IPA 未签名，可使用自己的证书签名。

- 移除调色、EQ、自适应听感、AirPods 增强和对应处理代码。上滑期间暂停新增播放器、预下载、环境光采样和推荐列表更新。滑动停稳后开始播放下一条并继续预加载。
- 推荐频道维护最多 50 条未观看视频的队列。在系统标为非计费、非低数据模式的网络上，等当前视频出画后，以低优先级下载实际视频。单文件上限 45 MiB，总上限 384 MiB。仅缓存可获得的普通文件视频，直播和流媒体播放清单不缓存。冷启动优先展示已缓存的视频。实际条数随网络、视频尺寸和系统缓存回收而变。
- 视频开始播放并出现画面后，从待播队列移除。正在播放的文件保留到换片时释放，避免中途打断。补入未看过的作品。推荐和关注按账号记录作品 ID，以及平台提供的稳定片源 ID。同内容被重新上传为不同片源时可能无法判断。搜索、主页和互动消息仍可主动打开已看过的作品。
- 图文独立分页并在手势结束时对齐。切到比例较小的图像时，空白区域显示当前背景，不再露出作品封面。
- 更多设置 → 外观提供深色、浅色、自动。自动跟随系统。视频上的浮层继续使用白色文字，保证画面上的可读性。
- 更多设置 → 诊断日志可启用、导出、清空。日志默认关闭，记录本应用的生命周期、内存、播放重试、网页进程、缓存和请求类型。最多轮转 6 个 512 KiB 文件，导出为本地 `.log`。不包含会话密钥、网页响应正文、消息正文或媒体 URL。系统终止原因仍需 iPhone 的 `JetsamEvent` 或崩溃日志。
- 互动消息的赞和评论回复可打开对应作品。平台给出评论标识时自动展开回复并尝试定位高亮，超出可读取范围会提示。评论保留只读。

本版改进：

- 评论区图片和表情包加载时显示系统转圈，完成后隐藏；失败显示加载失败，缓存命中不额外等待。点击打开原图时也在来源图片显示转圈，避免重复打开请求，离开页面后不弹出过期的预览。
- 信息主页移除左上角返回按钮，通过顶部频道滑块切换关注或推荐。
- 针对 0.20.0 的卡顿回归反馈，撤回强制 CDN 直连优先及 1 秒起播缓冲改动：优先使用平台播放地址，保留 CDN 地址作为失败备用，前向缓冲恢复 4 秒。此前持久化的直连优先记录也恢复相同选择。播放器仍使用远程流式读取与即时播放，不等待完整缓存下载。实际效果尚未经设备验证，不能据此确定用户卡顿的唯一原因。
- 预解码只能由停稳后的调度显式请求；开始滑动、应用失焦、后台清理以及当前视频停顿时取消未完成的相邻预解码。状态回调不再自行启动预解码，已取消回调不会覆盖新的预加载状态。当前视频出画前不新增相邻视频预缓冲或磁盘预下载。出画后只向前新建一条预缓冲，已有的上一条可以保留，播放器池仍有数量上限。资料补全不重建已经正常出画的播放器。日志增加片源类型、资源就绪时间、播放器复用年龄和首帧缓冲秒数；补充停顿时的等待原因、缓冲状态，以及实际传输字节数、请求数和传输时间。不记录媒体 URL。
- 原声列表每次向官网移动分享接口请求最多 50 条，再按真实返回展示；移动游标不前进时尝试官网桌面分页。公开样本实际返回 17 条，后续游标重复，仍不能保证完整分页。平台未返回更多时明确提示，不把重复作品当新作品。缺少作者资料的条目通过作品详情异步补全昵称和头像，合并同一作品请求，同时最多两条；平台不返回资料时保留加载占位。
- 边缘长按从 1.5× 起步，上滑约 28 点切到 2×，到 64 点切到设置的最高倍速；松手恢复。
- 左边缘侧滑按导航层级返回上一页；网页有历史时先返回上一网页。仅屏幕左边缘触发，最左 24 点留给返回手势，其余边缘继续支持长按倍速。登录和验证页返回时清理对应计时器与页面托管。

- 处于关注频道时，再点顶部“关注”刷新关注作品；提供震动和下方转圈反馈。切换频道不触发这项刷新反馈。
- 原声列表改用官网移动分享接口，打开时重新核对来源作品的原声 ID 与元数据，ID 改变后重建列表和网页。原声网页默认使用移动显示模式打开官方分享页。公开原声样本扩大请求后可读取 17 条带播放地址的作品；部分样本的后续分页重复，仍不能保证取得完整列表。
- 搜索历史每条有删除按钮，也可左滑删除该条；保留清空全部历史和搜索联想。
- 主页与搜索等三列作品封面展示点赞数，作品点赞变化同步到来源列表。
- 从列表进入作品后再切换作品，退出缩放动画对应当前观看作品；来源封面不在可见范围时先定位到该封面。
- 拖动播放进度时当前视频继续播放，独立缩略图用于预览；松手后提交一次目标进度，取消拖动保持实际播放位置。
- 边缘长按从 1.5× 开始，上滑约 28 点切到 2×，继续到 64 点切到设置的倍速；回滑可降档。更多设置可设为 2×～4×，默认 3×，松手恢复正常播放。弹幕移动速度随实际播放速度变化，暂停及缓冲时停住。
- 信息页“新的关注”“互动消息”和私信会话展示未读红点或未读数。平台有未读信息时更新；打开对应通知分类成功后标记已读，读取失败不会清除红点。未读数据受平台同步延迟影响。
- 播放界面的通知横幅位于弹幕使用区域下方。
- 消息、会话和互动通知先显示按账号隔离的缓存，再异步检查并合并更新。离开信息页保留页面和服务以供再次进入，不再每次创建网页连接；内容不变时不刷新，同顺序列表仅更新发生变化的行。离开页面停止轮询，退出账号清空缓存。缓存有效期 24 小时，内存上限 2 MiB，磁盘上限 8 MiB / 24 个文件；首次没有缓存时仍需联网读取。
- 根据 2026-11-27 的系统崩溃报告，修正进度条把系统手势当成拖动手势读取速度而触发的异常退出。图文导航也修正同类判断。
- 搜索、点赞、收藏等原生列表与打开的作品可在 5 分钟内恢复。保存关键词、标签、列表位置、当前作品和播放进度，返回仍回到来源列表。为控制占用，每个列表保留当前位置附近最多 180 条，作品播放列表保留最多 61 条，全部页面记录上限 2 MiB。官方网页自身的翻页位置不保存。
- 移除“立即开启画中画”按钮，保留自动画中画开关。
- 短时间内进程重新启动时，优先恢复推荐或关注页刚才的作品及进度。返回前台不删除续播记录；支持最多 5 分钟内恢复，并在切后台前和播放期间更新。可用的本地视频跟随作品保存，便于断网续播。
- 切离前台时先停掉额外界面更新，切回后优先恢复当前视频，稍后再预加载。诊断日志补充场景切换、后台清理结果和续播未命中的原因。
- 原声网页直接打开该原声真实的官方分享地址或官网音乐页，移除无效的自动关键词搜索兜底。额外读取平台详情提供的原声来源作品标识，核对原声 ID 一致后补入该作品。官网没有返回作品列表时明确显示读取失败，保留已识别内容。仍不能保证获取完整原声作品列表。
- 开启自动上滑时，划走的视频回看从 0:00 播放。切到后台再回来时，仍保留当前视频的播放进度。
- 展开评论时，回复会标出回复对象；还没有载入被回复的人，或平台没有提供昵称时，会提示暂不可见。
- 播放白条直接读取播放器时钟，按屏幕刷新移动。暂停、缓冲、上滑换片和退后台时停用帧更新。保留相对拖动。
- 相邻作品限量预缓冲，滑动中只接上已经准备的播放器。首次出画立即撤掉封面，短暂等待使用封面，约 0.48 秒后才显示播放加载指示。
- 在推荐页再点「推荐」有短触感和请求完成后消失的转圈。切换频道不触发这项反馈。
- 主页导航栏有放大镜，可按作品文案和话题查找并跳到首个结果。搜索只覆盖平台当前账号能读取的作品。
- 作品从封面展开和收回时用系统缩放转场，配合背景模糊与列表微缩。系统减弱动态效果开启时尊重设置。
- 读回复时只显示读取状态，请求结束后才出现收起。更多设置可直接查看最近诊断日志。新增进程号、非活跃状态、滑动帧间隔、预缓冲、首帧和播放停顿记录。短时间内重新启动，会尝试恢复刚才的作品和视频进度。恢复是本地续播措施，系统终止原因需设备日志确认。

- 原声页移除下载入口。显示本机通过平台原声 ID 识别到的作品，并合并官网明确返回的同一原声结果。官网接口不可用时仍可保留已识别作品。

按要求没有运行自动化或真机测试。交付检查覆盖云编译、打包资源、架构与哈希。
