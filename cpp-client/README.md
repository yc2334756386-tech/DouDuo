# 澄流 / DouGlass 0.3.0

## 本版修订

- 修正推荐读取把验证响应头直接当成失败的问题：先检查实际业务数据；读取等待网页 SDK 初始就绪，但不再把写请求专用的双重挂钩条件套到全部读取上。
- 媒体优先走平台返回的重定向播放地址，保留兼容码率与备用地址、相邻播放器预热。
- 登录后等待官网保存登录信息，再关闭页面；网页初始化前挂载防后台自动登出规则；已确认的会话加密保存到本机 Keychain，只在应用启动且缺少会话时尝试恢复。服务端已过期或撤销的登录仍需本人重新验证。
- 评论面板只执行自身平移动画，不再动画修改分页列表高度和滚动偏移；视频显示区域在固定页面中调整，保持播放。
- 倍速简化为长按视频固定 2×，松开恢复 1×，移除上滑变速。
- 信息页使用原生会话列表、原生聊天气泡和输入框；后台复用官网消息服务及本机登录态，用户界面不显示网页。实际会话同步仍取决于平台服务及登录状态。
- 右侧原“撑满”按钮改为耳机图标的后台音频开关，默认关闭。开启后离开应用继续当前音频，返回应用恢复视频画面。
- 下载原声和复制作品文案均显示确认框，取消不执行操作。

## 安装

GitHub Actions 使用 iOS SDK 编译 arm64。安装包为未签名 DouGlass-0.3.0-unsigned.ipa，可使用自己的有效证书在全能签等工具中自签。Bundle ID 保持不变。

iOS 26+ 使用系统液态玻璃；iOS 18–25 使用系统材质。
