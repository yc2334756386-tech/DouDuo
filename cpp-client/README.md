# 抖音极简版 0.20.18

延续以 0.7.0 构建 19 为底包的分支。支持 iOS 18 及以上的 arm64 设备。IPA 未签名，可使用自己的证书签名。

- 移除调色、EQ、自适应听感、AirPods 增强和对应处理代码。上滑期间暂停新增播放器、预下载、环境光采样和推荐列表更新。滑动停稳后开始播放下一条并继续预加载。
- 推荐频道维护最多 50 条未观看视频的队列。在系统标为非计费、非低数据模式的网络上，等当前视频出画后，以低优先级下载实际视频。单文件上限 45 MiB，总上限 384 MiB。仅缓存可获得的普通文件视频，直播和流媒体播放清单不缓存。冷启动优先展示已缓存的视频。实际条数随网络、视频尺寸和系统缓存回收而变。
- 视频开始播放并出现画面后，从待播队列移除。正在播放的文件保留到换片时释放，避免中途打断。补入未看过的作品。推荐和关注按账号记录作品 ID，以及平台提供的稳定片源 ID。同内容被重新上传为不同片源时可能无法判断。搜索、主页和互动消息仍可主动打开已看过的作品。
- 图文独立分页并在手势结束时对齐。切到比例较小的图像时，空白区域显示当前背景，不再露出作品封面。
- 更多设置 → 外观提供深色、浅色、自动。自动跟随系统。视频上的浮层继续使用白色文字，保证画面上的可读性。
- 更多设置 → 诊断日志可启用、导出、清空。日志默认关闭，记录本应用的生命周期、内存、播放重试、网页进程、缓存和请求类型。最多轮转 6 个 512 KiB 文件，导出为本地 `.log`。不包含会话密钥、网页响应正文、消息正文或媒体 URL。系统终止原因仍需 iPhone 的 `JetsamEvent` 或崩溃日志。
- 互动消息的赞和评论回复可打开对应作品。平台给出评论标识时自动展开回复并尝试定位高亮，超出可读取范围会提示。评论保留只读。

本版改进：

- 弹幕黑白候选区域至少连续覆盖约两个字宽，且连续三次采样达标才切换；过窄背景线条不触发换色。保留局部渐变，黑色字增加细浅色轮廓与低强度亮边，不加整条背景框。
- 评论图片退出不再立即合入挂起分页；在退出开始前恢复阅读位置并允许评论继续拖动，待读者主动滑到已加载列表末尾再发布挂起内容。预览期间保留不接收触控的评论可见快照，退出时覆盖原生 Zoom 自动调整来源视图导致的短暂位移，手指开始拖动立即撤掉快照；图片预览继续保留播放器状态，不再因为打开预览先暂停、关闭后再重启音频。关闭按钮触发后释放预览触控遮挡，让下层可以开始操作。系统 Zoom 自身的交互覆盖仍由 UIKit 管理，需真机确认。
- 已显示评论按评论/回复 ID 缓存真实行高，页面重挂载时使用已知高度估计，减少含大图行从统一 112 点估计值重新排版带来的偏移；宽度改变时丢弃旧高度。
- 滑动换视频的松手吸附及自动上滑接入全局曲线/速率，手指拖动仍保持 1:1；新拖动可打断吸附，从当前呈现位置接续。评论展开/收起保存 animator 与代数，点击关闭、再次展开、拖动横条可从呈现位置打断。通用 animator 允许交互与打断。系统 Zoom 无公开自定义贝塞尔接口，作品与图片保留原生连续缩放曲线，未冒用全局曲线覆盖它。
- 更多设置新增“画面与音频实验室”，所有增强默认关闭。MetalFX 空间放大接入 AVPlayer 的异步视频合成，以 Apple `metal-cpp` 的 C++ API 编码 GPU 命令；最多 1.5×，输出长边不超过 1920，不改变原片时间线。关闭时不创建该处理路径，显存或系统不支持时保留原图；动画/滑动期间及高温时普通缩放旁路。处理线程仅读取主线程公布的原子动画期限，不跨线程读取界面状态。此版本未实现视频插帧，也未声称恢复源中不存在的真实细节。
- 画面提供原始、自然、柔和、鲜明预设，与音频分开；图文仅在实际作品图片上应用预设，不影响头像、评论、界面。MetalFX 当前接在视频合成路径，图文只应用画面预设，未实施神经超分。
- 音频增强采用独立 C++ 八段 IIR，60 Hz～14 kHz 各段 ±12 dB，参数缓慢平滑与峰值保护；提供平直、人声、低音、柔和预设。自动调音参考实际音频低/中/高频能量做最多约数 dB 的缓慢修正，按均衡、人声、低音、柔和风格选择，不宣称任意音源都存在“最优”音色。音频回调不分配内存、不做 UI 或磁盘操作；不支持的 PCM 格式和基线 HLS 旁路原声。
- 核对用户提供的 Atang FPGA、AutoEq、OctaEQ：前者是 Verilog 多相机拼接，不是 iPhone 超分模块；AutoEq 是耳机校正参数生成器；OctaEQ 是 GPL 桌面 VST3。未拷贝这些项目的实现，音频 DSP 独立编写。实验室报告 MetalFX 插帧设备接口能力，但普通解码视频缺少运动/深度输入，没有放置无效的插帧开关。VideoToolbox 的 iOS 26 低延迟超分属于后续方案，当前仅检测 API 存在，未接入。
- 本版编译 9 个项目 C++ 源文件、43 个 Objective-C++ 源文件与 4 个网页脚本，另保留 Apple metal-cpp 的 Apache-2.0 SDK 头文件及许可证。并非整个 iOS 工程都成为纯 C++，未执行自动化或真机测试，性能和处理效果未经设备验证。
- 评论展开时，视频区域使用独立的立即单击收起手势，不再等待双击点赞判定；普通播放状态保留单击暂停与双击点赞。评论展开动画期间收到关闭操作会记住请求。
- 评论图片、表情包与头像改用内置图片预览，移除 Quick Look 页面、临时文件预下载等待及对应框架链接。已有缩略图立即显示，静态图后台补清晰版本，已载入的动图复用动画图片；保留加载转圈、失败状态、双指缩放、双击缩放及确认保存。打开与退出使用与三列作品相同的 UIKit Zoom 配置和模糊背景，没有系统文件名、标记工具栏或分享底栏。
- 打开评论媒体前，纯 C++ `ReadingPosition` 记录顶端评论/回复 ID、行内偏移与备用偏移；预览期间冻结列表滚动和评论结果发布，关闭后再发布待处理数据并按标识恢复原位置，减少安全区变化、分页和回复更新造成的错位。缩放档位与目标区域边界也放入纯 C++。
- 从三列列表进入作品时只立即解析选中的完整模型，其余保留轻量标识，显示或相邻预加载时再按需解析；完整列表仍可前后浏览。初始化时直接采用选中索引，并跳过首次定位前对非选中单元格的配置。新增 `explore.work_prepared` 日志记录转场前的作品构建耗时；原系统 Zoom 动画样式和时长继续保留。
- 按 Apple 连续缩放转场说明撤回三列作品打开/返回时的串行等待限制，原生 Zoom 的返回手势不再因已有转场而直接禁用；新打开/返回操作交给 UIKit 接续。播放器激活挪到下一次主循环并核对页面仍然可见，避免打断转场时同一帧先启动又暂停播放器。参考：`https://developer.apple.com/documentation/uikit/enhancing-your-app-with-fluid-transitions`。
- 本轮附件日志实际为北京时间 2026-11-27 15:13 的 0.15.0 / build 42，不能用于核验 0.20.16 转场。13:04 录屏在读取期间已从原路径消失，未完成逐帧视觉核对；不能据此声称已证明设备卡顿根因。按要求未运行自动化或真机测试。
- 开启日志时直接记录当前版本号与构建号，便于确认反馈对应的安装包。
- 按本轮要求撤回 12% 裁切限制，恢复“撑满画面”此前的竖屏裁切铺满行为；横屏、正方形、图文和评论缩小状态仍保持完整显示。
- 新增纯 C++20 `RenderBudget.cpp`，维护带期限的动画任务窗口；导航转场和通用动画开始前标记，完成后释放，取消的动画到期自动释放。动画期间暂缓环境光/取色采样、相邻作品预加载、列表整表刷新、图片提交和页面恢复记录采集。原生 Zoom、背景模糊、动画曲线与时长继续沿用原值。并非改变 iOS 私有调度器，也不能保证系统永不掉帧。
- 三列作品返回时缓存当前作品对应的来源视图，减少原生 Zoom 多次索取时重复滚动与强制布局；点赞等统计刷新延后至转场完成。图片在后台解码时立即缓存解码结果，大图加载可先复用已存在的封面缩略图。启用日志后，记录转场准备耗时、总耗时、帧回调最大间隔和长间隔数；这不是 GPU 实际呈现帧率实测。
- 根据提供的 `refresh.pip_start_timeout` 日志，微型 PiP 改为以有效内容尺寸启动，启动前已有内容更新，成功后再缩为 0.1 点；静默超时后仅补试一次常规比例尺寸。记录源视图尺寸、是否挂到窗口、系统 possible/active/suspended、启停回调及错误域/代码。前台 119fps 回调与 PiP 成功分开显示；实际是否成功仍需设备反馈。
- 本地核对 Material Color Utilities、TinyColor、BackgroundCheck 的源码后，弹幕取色改用 sRGB 线性亮度和实际黑白墨色的对比度比较；复杂纹理只扩大迟滞，不再强行使用白字。优先读取播放器实际视频矩形，直接使用缩小后 CGImage 的 RGBA 数据，取消一次中间位图重绘；图文同样使用当前图片和显示矩形。继续保留较大局部、横向渐变和固定字号，丢弃超过 0.2 秒的过期采样。参考与限制见 `docs/adaptive-contrast-and-transition-2026-11-28.md`。
- 评论排序与媒体适配几何继续迁入纯 C++；UI、系统播放器及 WebKit 保持原生接口适配。当前编译 9 个 `.cpp`、43 个 `.mm`，4 个网页适配脚本，未编译 Swift。
- 评论后续分页只追加新评论，不再每次返回数据都重排已读内容或重建整个列表；手动切换“最热/最新”时才对全部已加载评论重排。回复刷新也保留可见评论锚点，减少阅读位置跳动。
- 评论图片、表情包和文字内的单个表情统一提供系统加载转圈与失败状态。文字表情在请求前预留固定尺寸，图片就绪后只更换该位置的内容，不再替换整段文字改变行高；内嵌表情也可轻点查看和长按确认保存。复用时取消旧请求，内嵌表情限制解码尺寸。
- 信息页顶部固定显示消息连接/同步状态：正在连接、正在同步、缓存提示、已同步时间或同步失败。私信与关注/互动提示请求都计入同步状态；后台更新继续保留已有列表，离开页面停止状态动画。
- 高刷开关关闭后再次开启，会等待旧 PiP 完成停止再启动新会话；为未回调的待启动/待停止状态加入有限时长的核对，取消过期任务。状态直接结合当前开关与系统实际 PiP 状态显示，设置页持续更新可见状态行，不再残留“已关闭”，也不把前台回调读数当成 PiP 已开启的依据。实际设备行为尚未验证。
- 图集缩略图轨道拖到左右边缘并按住后，持续向该方向浏览至图集首张或末张，移出边缘后继续直接跟手拖动。位置以增量更新，边缘推进后反向拖动不跳回旧触点。中央选框固定，松手立即停止并收起；离开作品、切后台和移出窗口也会取消边缘更新。

- 恢复三列作品原有的系统原生 Zoom 弹入/弹出动画，包括背景模糊、来源封面定位与列表微缩；移除自定义短转场及其动画时长限制。全局动画曲线和速率设置保持用户当前值。后台保存、图片解码尺寸、连续点按衔接等性能处理继续保留。

- 原二维亮度遮罩会沿画面亮暗边界斜着穿过字形。本版对每条弹幕按字高取背景亮度，保持各处横向独立变色，纵向不再生成斜切遮罩；仍保留平滑与迟滞。深色字内增加幅度很小的垂直炭黑色阶，用字面明暗和细浅轮廓形成层次，不加外阴影、模糊或底板，表情附件不改为纯黑。
