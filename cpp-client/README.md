# 抖音极简版 0.7.0

C++20 / Objective-C++ 原生 iOS 客户端，最低 iOS 18，arm64。iOS 26 及以上使用系统 Liquid Glass。图标与 Bundle ID io.github.yc2334756386.douglass 保持不变。

这是未签名 IPA，需要用本人有效证书通过全能签等工具自签。按用户要求，不运行自动化或真机测试；编译与包检查不代表设备行为和平台接口已通过验证。

## 此版修正

- 搜索、喜欢、收藏等结果打开作品时进入同一导航栈，返回原列表，避免全屏转场恢复错误导致黑屏。其他全屏页面保留横向进出。
- 作品操作和更多设置的面板以 bounds/center 布局，动画不再重复改写已缩放的 frame；收回沿触发位置反向进行。
- 进度条改为独立横向手势控件，整条轨道均可拖动，显示真实取帧预览并在松手时跳转；点按不跳转。取消拖动保持原位置，网络取帧仍可能等待。
- 评论顶部横条下拉时，面板位置与上方视频／图文的可用区域实时联动；取消回弹，达到距离或速度门槛关闭。同一作品保留评论位置。
- 后台音频开关避免重复设置正在播放的播放器速率，后台续播使用同一个播放器；切换后台后停止画面采样与卡顿自动重建。实际流畅性未做设备验证。
- 通知提示移至上方，避开底部作者名与作品文案。
- 点赞爱心随机向左或右倾斜；原有触感、保存确认和弹幕复制确认继续保留。

## 调色

更多设置 → 画面 → 视频与图文调色。

- 同一套 Core Image 渲染应用于视频和图文。关闭开关保留原色；保存的媒体仍为原文件。
- 曝光 EV、对比度、高光、阴影、白色色阶、黑色色阶、色温、色调、饱和度、自然饱和度均可填写数值。
- 曲线提供 5 个可编辑输入／输出点；X 需从小到大。
- HSL 按红、橙、黄、绿、青、蓝、紫、洋红分别编辑色相、饱和度和明度。
- 阴影、中间调、高光色轮以色相角度与强度定义，提供分离色调平衡。
- 预设：原始、自然通透、暖色人像、冷调、柔和胶片、黑白。选择预设会替换当前参数，再按需修改。
- 所有参数保存至本机，在各项明确显示的范围内输入小数；无效或非有限数值不应用。调色可能增加设备功耗，HDR／受保护媒体和画中画下的实际表现未做设备验证。

## 动画、字体与刷新率

- 更多设置 → 交互 → 全局动画曲线与速率。可拖动贝塞尔控制点，使用标准、线性、缓出、回弹预设，或填写两个控制点；X 为 0～1，Y 为 -1～2。动画速率 0.2～4 倍。
- 应用的菜单、全屏转场、评论面板与视频布局、爱心及展开动效使用此配置。系统拥有的导航、键盘、预览、提示框动画与弹幕匀速滚动仍遵循各自机制。
- 强制 120Hz 选项向系统请求设备可用的最高刷新率，最多 120Hz。关闭释放该请求并交回默认 ProMotion 策略；低电量、温度、设备能力与 iOS 策略仍可能限制实际刷新率。
- 弹幕描边选项已删除。保留阴影与字号，增加 R/G/B 整数输入，每项 0～255。
- 字体可选系统样式、已安装字体，或从文件导入 TTF／OTF／TTC。导入文件保存在本机，重启重新注册；单个文件最大 30MB。

## 评论与回复

更多设置 → 交互 → 开启评论及回复，默认关闭。

- 原生输入框支持文字、平台表情、单张图片和表情包图片，支持评论、回复及楼中楼回复。
- 图片点击发送后才上传，以官网临时上传凭据提交至 ImageX，凭据只在内存中处理。仅在平台回传有效评论 ID 后显示已发送；失败保留草稿，不自动重发。
- 评论点赞／取消点赞先有界面与触感反馈，平台失败时回退。
- 长按复制评论新增二级确认，确认后复制并触感反馈。
- 语音入口当前为语音转文字：申请麦克风和语音识别权限，将识别结果放入草稿，由用户检查后发送文字。未实现原始录音语音评论；官网现有接口没有可确认的原始语音评论发布入口。
- 不进行任何自动发评或真实账号写入测试。是否接受文字、图片、表情和点赞由平台权限、登录与风控结果决定。

## 搜索、图集与原声

- 我的 → 喜欢／收藏新增关键词查找，匹配文案或作者。对已读取列表即时过滤，继续分页读取更多；一轮最多自动读取 40 页，仍可手动继续。只有全部可读取页面结束后才提示搜索完毕，不声称检索隐私或不可读取内容。
- 图文下方显示当前图片位置小点；在小点区横向拖动展开缩略图条并快速查找，松手收起。缩略图单独限制尺寸，减少内存占用。
- 搜索保留联想、历史与清空，视频／用户切换，官方网页手动翻页并导回。每轮新增结果贴“新”，下一轮移除上一轮的标记。
- 原声头像打开使用该原声的作品。原声网页显示官网“服务出现异常”时给出说明，可点击右下角刷新按钮切换备用分享网页；自动读取也尝试该入口。仅导入实际取得的结果，不承诺官网异常可由客户端修复。
- 原有收藏音乐按序循环、EQ、系统空间音频、画中画、自动上滑、长按 1.5～3.0 倍速、过滤与环境光继续保留。退出音乐页面停止其播放，退到系统后台则继续。
- 主页显示平台置顶作品；“定位刚刚看过”悬浮玻璃按钮手动定位。IP 省市仅按平台实际 IP 字段显示，作品发布地另作区分。

## 构建与检查

GitHub Actions 使用 macOS / iOS SDK 执行 cpp-client/scripts/build-ipa.sh，生成 build/douglass/DouGlass-0.7.0-unsigned.ipa 与 SHA256.txt。

检查范围为源码审查、网页脚本语法、云编译、安装包资源及哈希。不运行自动化或真机测试，不声称原声服务、发评、回退黑屏、动画、调色、120Hz 或后台播放已做实机确认。

上游 DouDuo 的 MIT 许可随包保留。本应用独立于抖音；账号与缓存存于本机，没有开发者业务后台或统计 SDK。
