# 抖音极简版 0.6.0

C++20 与 Objective-C++ 原生 iOS 客户端，由 DouGlass 分支继续开发。最低 iOS 18，arm64；iOS 26 及以上使用系统 Liquid Glass。应用图标继续使用用户提供的原图。

这是未签名 IPA，需要用本人有效证书在全能签等工具中自签。Bundle ID 保持 io.github.yc2334756386.douglass。按用户要求，此版不运行自动化或真机测试；云编译和安装包检查不代表实机功能已验证。

## 保存、主页与位置

- 视频、图片、封面、音频下载与确认后的文字、弹幕、链接复制均加入触感；评论图片与表情包保存共用保存反馈，后台音频开关也有触感。
- 主页保留平台返回的置顶作品及标记，置顶内容排在普通作品之前。
- 从作品进入主页后不自动滚动，底部提供“定位刚刚看过”悬浮玻璃按钮，点击才开始寻找与定位。
- IP 属地按平台实际 IP 字段格式化；有省市时显示“省·城市”，只有省份时保留省份。作品发布城市继续与作者 IP 区分，不用发布地替代 IP 城市。

## 后续追加的播放与设置调整

- 后台音频沿用同一个 AVPlayer，后台停止画面取样与自动卡顿重建；回到前台先重连视频层并给予恢复时间，保留播放位置。
- 右侧按钮可点击，纵向滑动继续交给视频翻页；长按边缘仍可加速。
- 进度条再次下移，点按不跳转也不显示预览；只有横向拖动才移动位置、显示缩略图。
- 评论顶部横条扩大拖动区域，下拉可关闭，取消时回弹。
- 环境光、字号、倍速等控件改为标题和操作区分开的自适应布局。
- 长按加速可设置 1.5～3.0 倍，默认 2 倍。自动上滑可在视频播完后切换下一条；打开评论时保留当前作品循环。
- 增加原生画中画开关及手动开启入口，需设备和系统支持。打开后允许 iOS 在退到后台时自动进入画中画。
- 增加三段 EQ：低频 100 Hz、中频 1 kHz、高频 8 kHz，各 ±12 dB；提供平直、低音、人声、明亮与自定预设，通过实际音轨处理实现。受保护或系统不允许处理的音轨可能保留原声。
- 杜比全景声选项控制系统空间音频路径，仍需兼容音源、输出设备及系统支持。此开关不会把普通立体声音源变成杜比全景声；选择系统空间音频时暂停 EQ 处理。
- 弹幕新增颜色、描边、阴影、字体样式及系统字体选择，设置保存在本机。

## 0.6.0 更新

- 原声左侧旋转头像与原声文字统一打开“使用这首原声的作品”。原声页提供“网页查看原声作品并导回”，可手动翻页、完成验证后重复导入。
- 搜索输入时读取官网联想词，突出匹配文字，支持点击搜索或点箭头填入；本机保留最近 30 条搜索历史，支持一键清空。
- 搜索及原声网页每轮导入只给本轮新增内容贴“新”；下一轮移除上一轮标记，重复 ID 不追加。
- 打开评论隐藏进度条及时间，回收其占用高度来放大视频；同作品评论位置继续保留。
- 顶部玻璃容器只围住关注、推荐、信息，头像和搜索按钮位于容器外。
- 进度条整段都可开始拖动。点按不跳转、不弹缩略图；横向移动超过 5 点后显示真实帧预览，取消拖动不跳转。
- 作品操作与更多设置从触发位置弹性展开并反向收起。普通全屏页面改为从右侧进入、向右退回，导航栈内保留原生交互返回，取消侧滑会回到当前页面。
- 更多设置增加“优化画质”“提高帧率”，根据平台返回的分辨率、码率及实际帧率选择片源，切换保留播放位置。原视频没有更高清或高帧率片源时，客户端无法凭空增加视频细节或帧数。
- 收藏音乐与原声播放绑定到发起播放的页面。退到后台继续播放；在软件内离开该音乐页面或切换收藏分类时停止，清除系统媒体信息，并通知首页恢复视频。返回视频页也会清除遗留原声播放器。

## 搜索更多页与用户

1. 打开搜索，在“视频／用户”中选择类型，输入关键词搜索。
2. 需要更多结果时，点击“网页翻页并导回”或右上角地球按钮。
3. 在官方搜索网页手动翻页或下滑，等结果加载出来；如遇验证，在该网页自行完成。
4. 点击下方“导入已加载结果并返回”。已加载的真实作品或用户会追加至原生列表，重复 ID 会去重。
5. 再次进入网页会保留同一关键词和类型的页面，继续翻页后可再次导入。重新搜索或切换类型会重置网页。

网页导入从官方搜索响应和对应结果卡片中读取数据，不自动翻页或解决验证。是否能加载下一页、是否能读取作品地址，仍由官网提供的内容决定；未取得结果时会保留网页并提示。网页导入后，下拉保留已导入结果；重新提交搜索可重置列表。

## 此版交互

- 搜索、主页等原生页面顶部改为实时取景的渐隐模糊，移除导航栏背景的直线边界。主播放器顶部为“左侧头像／关注·推荐·信息玻璃滑块／右侧搜索”；在推荐频道再次点击推荐可刷新。
- 评论面板与视频缩放使用同步过渡，面板铺满屏幕宽度，以当前视频或图文封面模糊处理为背景；打开评论持续播放，点击上方视频收起。弹幕不因打开、收起评论或暂停而清空。
- 同一作品关闭、再打开评论时保留滚动位置、已加载评论及展开回复；切换作品、账号或刷新内容时清除。回复直接在该评论下展开与收起。
- 评论新增“最热／最新”：分别按已加载评论的点赞数、时间排序，界面注明范围。官网接口没有可靠的全站最新排序参数，此功能不声称包含尚未加载的评论。
- 点击可见弹幕弹出复制确认；评论文字仍支持长按复制。评论图片、表情包可预览，长按保存先确认。
- 主页长按头像保存先确认；他人主页添加关注／取消关注与拉黑／解除拉黑。拉黑先确认，操作失败显示平台错误。
- 拖动白色进度条显示更大的真实帧预览，按横竖视频比例布局，显示拖动时间和总时长。取帧缓存有内存上限；网络取帧仍可能有等待，不以封面充当当前帧。
- 视频左右边缘长按加速可配置为 1.5～3.0 倍，松手恢复，开始时有触感；直接调整现有播放器速率。中间长按视频或图文打开液态玻璃操作菜单，提供保存当前媒体、封面、原声及复制文案、链接。原声下载、文案复制先确认。
- 点赞、收藏先更新界面和触感，再后台提交及核对，失败回退；双击视频显示动态爱心。点赞、评论、收藏使用一致的图标尺寸。
- 右侧后台音频开关有状态动画；右侧工具栏允许滑动穿透，边缘长按仍可加速。右下角更多设置使用下方实时画面的原生玻璃材质，不使用静态封面。
- 实时环境光根据视频帧或图文颜色更新，提供亮／中／暗／很暗／关。设置保留广告过滤、直播过滤、已刷过滤及弹幕开关、字号；已刷记录按账号保存在本机。
- 文案可展开；上方作者文字不再打开主页，头像仍可进入。主页、喜欢、收藏、搜索作品为三列，显示发布日期，支持通过悬浮按钮定位刚刚看过的作品。
- 首页显示平台实际提供的作者 IP 属地与发布日期；无法取得时不伪造城市，作品发布地另作区分。
- 原声页读取作品和收藏；收藏音乐直接在列表按序播放，自动翻页并在末曲后回到首曲，支持后台播放及系统下一首、上一首，在软件内退出音乐页面则停止。锁屏、控制中心和灵动岛由 iOS 按设备与系统状态显示。
- 保留原生私信与互动消息、系统加载转圈、全局边缘返回；弹幕支持平台表情。账号数据保存在本地 WebKit 与 Keychain，启动时恢复有效会话，不伪造平台已撤销的登录。

## 构建

GitHub Actions 的 DouGlass C++ unsigned IPA 工作流使用 macOS / Xcode 云端工具链执行：

```bash
bash cpp-client/scripts/build-ipa.sh
```

产物为 build/douglass/DouGlass-0.6.0-unsigned.ipa 与 SHA256.txt。编译源文件包括全部 cpp-client/*.mm 和 Core.cpp，附带网页适配脚本及上游 MIT 许可。

源码语法检查、云端编译、产物哈希和包结构核对是此次交付的检查范围。播放、登录、官网接口、动画和后台行为未做实机验证。原生界面通过抖音官网环境使用本人的登录与服务，没有开发者业务后台或统计 SDK。
