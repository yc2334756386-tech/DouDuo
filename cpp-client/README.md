# 抖音极简版 0.9.0

C++20 / Objective-C++ 原生 iOS 客户端，最低 iOS 18，arm64，iOS 26 及以上使用系统 Liquid Glass。应用标识为 io.github.yc2334756386.douglass，保留用户提供的图标。IPA 未签名，使用自己的有效证书通过全能签等工具签名。

## 本轮修正

- 后台播放恢复较简单的同播放器续播方式：进入后台前分离视频显示层，不寻址到零、不重建正在播放的音轨，停止环境光取样、缩略图生成与 120Hz 请求；返回前台再恢复画面。移除每秒多次的音轨扫描。EQ 在作品激活时按设置挂接，不处理每个预加载视频。
- 预加载范围减为当前作品前后一条；图片缓存与帧缓存限制分别降到 32MB 和每个单元 8MB，远离当前页的图集图片释放。内存警告和后台清理闲置播放器及隐藏原声网页。隐藏网页进程若在后台被系统终止，延后到前台重建。
- 上述修改用于降低后台资源压力。没有设备崩溃／Jetsam 日志，不能断言用户报告的退出后重启全部来自同一个原因，也不能保证 iOS 永不清理后台。
- 移除应用安装的全局侧滑退出，并关闭导航栈侧滑手势；保留明确的返回／关闭按钮。
- 作品操作、更多设置改为保持原有圆角外形的对称展开与收回，取消缩成微型矩形页面的效果。
- 曲线编辑每次先清除旧画面，避免切换预设后曲线重叠。默认曲线改为缓出，速率 0.9；升级时仅替换旧默认值，保留用户主动选择的其他曲线／速率。

## 评论

更多设置 → 交互 → 开启评论及回复，默认关闭。

- 评论面板底部改成液态玻璃内嵌输入框；点评论正文或行直接回复，回复对象与草稿显示在同一输入区，键盘出现时输入区跟随上移。
- 删除每条评论的右下角回复按钮。展开／收起楼中楼仍在父评论下方，不打开二级回复页。
- 支持文字、平台表情、单张图片或表情包图片；点击发送后才上传和发布，平台返回实际评论 ID 后插入列表，失败保留草稿。
- 删除语音输入及麦克风／语音识别权限。
- 自己的评论或平台明确允许删除的评论，可以左滑删除，或从长按文字的操作菜单删除。删除经确认并收到平台成功结果后才移出列表，不能删除无权限的他人评论。
- 作品与评论点赞／取消点赞使用即时反馈、串行提交与最后意图合并；修正字符串“0”被当成已点赞，以及接口字符串状态码解析错误。平台拒绝时恢复已确认状态并说明原因，不伪造成功。
- 评论、作品日期显示到小时与分钟。评论位置记忆、图片保存确认、复制评论确认继续保留。

## 播放、信息和列表

- 进度条从当前白色进度点按手指位移相对调整。在轨道任意处起拖均不会先跳到手指落点；点按不跳转。
- 拖动时优先复用当前播放器已缓冲的解码画面取缩略图，并保留小尺寸缓存与取帧回退。松手精确寻址并恢复原播放状态。未缓冲的网络片段仍可能等待，不承诺任何片源均逐帧即时响应。
- 信息改成与关注／推荐并列的根频道，内嵌原生新的关注、互动消息及真实会话列表；会话详情和通知分类仍使用原生详情页。消息内容继续通过官方网页会话同步，不虚构官方购物或系统会话。
- 搜索、主页、喜欢、收藏、原声作品列表使用系统图片展开式进出动画，起点为点选封面，退出回原列表。保留导航栈以避免旧的黑屏返回路径。
- 图文小点滑动切换图片时提供触感。

## 调色和 HDR

更多设置 → 画面。

- 调色界面显示当前作品封面预览，点击可对比原图。修改参数后使用与画面相同的滤镜更新；预览是封面图片，并非播放中的实时视频。
- 新增质感 -100～100 与锐化 0～100；保留曝光、对比度、高光、阴影、黑白色阶、色温／色调、饱和度／自然饱和度、5 点曲线、8 色 HSL、色轮及分离色调。
- 预设包括原始、自然通透、暖色人像、冷调、柔和胶片、黑白、护眼模式、臻享模式。护眼模式为暖色与柔和高光的显示预设，不是医学功效。
- 新增源 HDR 开关，使用系统 HDR 元数据与图片高动态范围显示。依赖实际 HDR 源、设备、屏幕和系统状态；不会将 SDR 素材伪装为 HDR。开启时，检测到 HDR 视频的调色合成将旁路，优先保留源动态范围；HDR 图片同样优先保留原始数据。关闭不改变下载的源文件。

## 原声作品的边界

- 修正原声网页采集遗漏：按被请求的原声 ID 绑定网页，只有确认来自同一原声列表的响应，才接收未带重复 music 对象的作品。
- 打开原声时保留实际刚看过且原声 ID 匹配的作品；该项来自真实作品记录，不代表成功获取完整原声列表。
- 官方原声 API 与备用分享网页继续按实际返回内容读取，手动网页导回入口仍保留。若官网本身提示服务异常，客户端无法保证修复服务；不会生成虚假的原声作品或声称该故障已验证解决。
