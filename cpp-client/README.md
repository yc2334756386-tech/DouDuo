# 澄流 / DouGlass 0.2.0

C++20 数据核心与 Objective-C++ 原生 iPhone/iPad 客户端。iOS 26+ 使用系统 Liquid Glass，iOS 18–25 使用系统材质。

## 本版

- 适中码率兼容 MP4、相邻视频预热、播放器复用、短起播截止和备用地址恢复；追加推荐不再重建全部播放器。
- 点击推荐刷新；顶部设置、关注、搜索、信息、真实账号头像。长按关注打开关注列表。
- 右侧玻璃工具栏：头像、点赞、评论、收藏、撑满和更多；双击视频点赞，成功互动触感。
- 固定高度玻璃评论面板，作品在上方继续播放；回复原位展开/收回；头像到主页；图片/表情预览与保存。
- 两侧长按从 1.5× 起，向上滑线性加至 3×；进度拖动显示实际视频帧预览；视频弹幕开关。
- 视频/图文保存、单张或全部图集保存、文案复制、原声保存及同原声作品。
- 个人作品、喜欢、收藏、收藏音乐、关注列表、用户主页及搜索。主页按作品 ID 有限分页定位刚刚看过的作品，显示发布日期。

## 位置字段

优先显示平台实际返回的作者 IP 属地。只有作品地区码时使用上游城市字典，标注“发布地”。没有城市级数据时不推算或伪装为作者精确 IP 城市。

## 安装与构建

GitHub Actions 执行 bash cpp-client/scripts/build-ipa.sh，使用 iOS 26+ SDK 编译 arm64，输出 build/douglass/DouGlass-0.2.0-unsigned.ipa。

导入全能签等工具，用自己的有效证书和描述文件自签。Bundle ID 保持不变，可以覆盖上一版保留本机网页会话。

按用户要求不运行自动化或真机测试；编译成功不等于真机交互和起播性能已经验证。搜索翻页和同原声作品等受平台接口、隐私和验证状态限制。信息页当前使用共享登录态的官方网页。
