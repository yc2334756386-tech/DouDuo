# 抖音极简版 0.4.0

由 DouGlass / 澄流分支继续开发，C++20 与 Objective-C++ 原生 iOS 客户端。Bundle ID 不变，仍为未签名 arm64 IPA，支持全能签等工具用本人有效证书自签覆盖安装。

## 此版更新

- 应用名改为“抖音极简版”，图标使用用户提供的 1024px PNG 原图生成各尺寸。
- 顶部移除设置按钮；作品右下角三个点打开原生液态玻璃二级选项页，提供广告过滤、直播间过滤、已刷视频过滤、弹幕开关和字号设置。过滤作用于后续推荐，当前播放作品保留；已刷记录按账号保存在本机。
- 点赞、收藏使用与评论相同的图标配置，修正刷新状态后变小的问题。
- 暂停时冻结已有弹幕动画，继续时恢复；打开/收起评论不清空弹幕。原声头像在播放时旋转，暂停时冻结。
- 评论面板背景改为当前视频或图文封面的模糊图层；评论图片、表情保存需二次确认。
- 原声页新增平台收藏/取消收藏；收藏音乐使用持久播放器和系统 Now Playing、锁屏/控制中心媒体控件，切后台不主动暂停。支持灵动岛的机型由 iOS 按系统规则显示媒体入口。
- 主页、喜欢、收藏及其他作品结果改为三列封面网格，保留日期和“刚刚看过”定位；收藏音乐仍使用曲目列表。
- 下载视频、开始长按 2 倍速加入触感。原声下载与文案复制继续先确认。
- 保留原生消息列表与聊天界面、固定 2 倍速、后台音频开关，以及登录保存、加密本机会话快照、启动恢复和后台自动登出防护。登录关闭前等待官网保存提示处理；不伪造或恢复平台已撤销的凭据。

## 编译与验证

GitHub Actions 执行 cpp-client/scripts/build-ipa.sh，使用 iOS SDK 编译并打包 DouGlass-0.4.0-unsigned.ipa。iOS 26+ 使用 Liquid Glass；iOS 18–25 使用系统材质。

按用户既有要求不运行自动化或真机测试。源码检查、云编译与安装包核对不能证明平台接口、登录稳定性、后台声音和灵动岛在真实设备上均已通过验证。

原生界面仍通过抖音官网运行环境使用本人的登录和平台服务；网站接口或验证状态可能影响读取。位置只显示平台实际字段，并区分作品发布地与作者 IP 属地。

保留根目录 MIT 许可与应用内 NOTICE。没有开发者业务后台和统计 SDK。
