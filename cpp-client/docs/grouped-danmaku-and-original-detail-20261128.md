# 0.20.20：完整字符分组变色与原画增强

用户要求：黑字边缘减淡；背景至少覆盖两个字时才变色，同组的字一起变；画面预设增强质感/清晰度并保留色彩。

## 弹幕

旧实现虽然检查候选背景区域的宽度，输出仍是随屏幕移动的像素遮罩。字形穿过背景边界时，遮罩可以切进单个字的边角，无法保证两个完整字共同切换。

新实现复用低分辨率采样，按实际显示位置读取背景线性亮度。TextKit 仅在新增弹幕、字体或尺寸改变时给出完整组合字符及附件的位置；C++ `GroupedInk` 将可见字符通常两两分组，奇数末尾并为三字组，空白不计数。每个字符至少 82% 的背景支持同一种墨色、整组一致且连续两帧采样确认后，整组才一起切换。混杂背景、局部角落或部分出屏不形成新的切换。

遮罩固定在文字局部坐标，只包含整组状态，边界落在字符之间；保留 0.14 秒整组渐变。去掉屏幕像素羽化与每帧移位时钟。黑字柔光移除，细浅描边宽度从字体的 2.2% 减到 0.75%，不透明度从 58% 减到 25%，字面中部稍微提亮。白字阴影沿用用户开关。

## 原画增强

新增画面预设索引 4，原始/自然/柔和/鲜明索引不变。纯 C++ `PicturePreset` 保存纹理与清晰度参数；系统图像桥接在两个尺度使用 `CISharpenLuminance`，可用时分别使用 2.4 / 0.8 半径和 0.14 / 0.32 强度。前后裁切到原范围，避免边缘扩展。饱和度、整体对比度和亮度偏移保持单位值，不应用风格调色；锐化会改变局部亮度，不意味着像素完全不变或恢复缺失细节。

视频与静态图文共用同一处理入口。视频转场期间暂缓细节处理，仍沿用原播放器与解码路径；参数不受设备支持时保持原图或旁路对应尺度。没有新增插帧或神经网络处理。

参考：Apple Core Image `CISharpenLuminance` 官方说明，`https://developer.apple.com/documentation/coreimage/cisharpenluminance`。

## 验证范围

依照用户先前要求不执行自动化或设备测试。核对源码调用、云端编译、包内资源、实现标记、架构与哈希。颜色观感、复杂字体排版及设备负载尚未经真机确认。
