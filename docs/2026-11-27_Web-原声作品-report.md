# 原声作品读取记录

## 结论与范围

本次修正原声入口误开普通关键词搜索页的问题。入口改为平台提供的原声分享地址，没有有效分享地址时使用带原声 ID 的官网音乐页。删除自动按原声标题搜索的兜底，保留实际识别到的同原声作品。

官网音乐详情正常，不能据此认定其作品列表正常。在新建、未登录浏览器的核验样本中，官网作品列表自身返回空响应，所以本次不承诺已经获得完整原声作品列表。[范围记录](cases/original-sound-20261127/scope.md)明确区分该公开样本和用户的实际设备。

## Path

- P1，path_type=callflow：原声 ID → 官网音乐页面 → 官网 SDK 请求 `music/detail` → 返回详情（E1）→ 请求 `music/aweme` → 空正文（E2）→ 不能解释为没有使用过该原声的作品（F2）。
- P2，path_type=callflow：应用原声页 → 平台原声分享地址或该 ID 的官网音乐页（修正 F1）→ 仅在官网实际加载到同 ID 作品后允许导回。

## 交付与限制

本版同时修正拖动进度条时误移动主播放器：缩略图独立解码，主画面保持不动，松手才提交目标进度。边缘长按从 1.5× 起步，向上滑动线性提高到用户选择的 2×～4× 上限。消息按账号缓存，进入后异步检查更新。

原声列表仍需要平台实际返回作品。公开浏览器读取不等同于 iOS 真机验证，也不能证明每一首原声都有相同返回。捕获过程具有响应体和事件预算，其他未保留响应不作为“接口不存在”的证据。临时浏览器均由 REA 结束并清理。
